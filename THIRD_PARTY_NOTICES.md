- **VRGDG SeedVR2 TensorRT Studio donor** (vrgamegirl19/VRGDG-SeedVR2-TensorRT-Studio, **Apache-2.0**): studied 2026-08-31, in two distinct ways that deserve separating.

  *Product shape — technique provenance only.* Preview before committing, four compare views, resumable chunk checkpoints, non-destructive finishing, project-based history. Independently implemented here on this repository's own gateway, lane routing, sealing and rental rails.

  *TensorRT VAE approach — genuinely derived, and credited as such.* Three attempts to compile SeedVR2's decoder through PyTorch's own compiler failed on rented hardware (data-dependent export guard, a rank-10 tensor against TensorRT's rank-8 limit, then a CUDA illegal memory access). Reading the donor's `tools/` showed why: it does not use that compiler at all. The approach taken from it is **ONNX export with the legacy tracer at a fixed shape → TensorRT-RTX's own ONNX parser → a fixed-shape engine run over feathered spatial tiles**, together with the three model reconfigurations that make the decoder traceable (`disable_slicing`, removing the `InflatedCausalConv3d` memory limits so the chunked-GroupNorm path does not emit ONNX sequence operators, and clearing `UpDecoderBlock3D.slicing`), the export flags that keep operators portable (legacy tracer, opset 20, MATH SDPA, cuDNN disabled, no constant folding), and the observation that `4n-3` output frames per latent frame is what fixes the supported temporal batches. Our `trt_engine.py`, `trt_vae.py` and `rank_patch.py` are written from scratch and differ substantially — engine caching keyed by GPU and library version, a bit-identical-or-refuse rewrite of the causal padding, and speed/accuracy gates that discard an engine that is slower or different — but the working path is the donor's, and this note is the attribution. Apache-2.0 is one-way compatible with this repository's AGPL-3.0-or-later; the combined work remains AGPL-3.0-or-later. No donor code, assets or text were copied. See `docs/RESTORE_STUDIO.md`.

NVIDIA's own licence terms for TensorRT and its Python packaging apply to any machine that installs them. `torch-tensorrt` is deliberately NOT installed — this path uses TensorRT's ONNX parser directly. - **`rank_patch.py`** rewrites two helper functions of the pinned upstream SeedVR2 pack at runtime (`extend_head`, `cache_send_recv`) so their `torch.tile` becomes an equivalent `expand`. Nothing is vendored and upstream is unmodified on disk; the replacement is proven bit-identical with `torch.equal` before it installs itself, and refuses to install otherwise.
