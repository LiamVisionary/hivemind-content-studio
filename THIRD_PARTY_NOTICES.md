- **Podcli** (nmbrthirteen/podcli, AGPL-3.0-only): not vendored in this tree. `scripts/install_podcli.sh` clones it to `vendor/` (gitignored) at pinned sha `e204f983906fb2b56bf365396e509d5c2a8f2e69` and applies three patches from `patches/`. It is invoked as a separate program, not linked. Two patches are functional (`ffmpeg8-ass-filter`, `remotion-caption-pages`, which adds the `branded-legacy` style). The third, `podcli-ai-select-default-off.patch`, is a **safety** patch: stock Podcli sets `ai_select` true by default and pipes the full episode transcript into whichever of `claude` or `codex` it finds on PATH (`backend/services/claude_suggest.py::_run_ai_command`), so a render would send creator material off the machine merely because an agent CLI is installed. The patch defaults that off, adds an explicit `--ai-select` opt-in, and hard-gates the single spawn point behind `PODCLI_ALLOW_AI_CLI`. `auto-clipper doctor` re-verifies the gate on every run and fails the install if it is missing. The patch files contain donor context lines and are themselves derivative works under AGPL.
